# Pyramid Principle — Structuring the Story Before the Slides

The Pyramid Principle (Barbara Minto, McKinsey) is the foundation of every good executive deck. It is a way of organizing ideas so that the answer comes first and is supported by a small, MECE set of arguments — each of which is itself supported by data.

## Why It Matters

Executives make decisions under time pressure. If the recommendation is buried on slide 14, half of them never reach it. The pyramid forces you to lead with the answer and earn the supporting detail. It also stress-tests your thinking: if your three Key Lines don't actually add up to the Governing Thought, you discover that *before* building 20 slides.

## The Three Levels

```
                ┌─────────────────────────────┐
                │     GOVERNING THOUGHT       │
                │  (one sentence: the answer) │
                └──────────────┬──────────────┘
                               │
        ┌──────────────────────┼──────────────────────┐
        │                      │                      │
   ┌────▼────┐            ┌────▼────┐            ┌────▼────┐
   │KEY LINE │            │KEY LINE │            │KEY LINE │
   │   #1    │            │   #2    │            │   #3    │
   └────┬────┘            └────┬────┘            └────┬────┘
        │                      │                      │
   data, exhibits          data, exhibits         data, exhibits
```

### Level 1 — Governing Thought

**Definition:** A single sentence that answers the question the analysis was meant to answer. It is a *synthesis*, not a *summary*.

A summary lists what was found ("We found A, B, and C"). A synthesis explains what those findings mean together and what to do about it ("Because of A, B, and C, we should do X").

A good Governing Thought:

- Is one sentence (not a list, not a paragraph).
- Includes a recommendation or clear direction.
- Makes a claim that would be false if the Key Lines were false — i.e., the Key Lines actually do support it.
- Couldn't be guessed without the analysis. If it could, the analysis added no value.

**Examples:**

| Weak (summary) | Strong (synthesis) |
|---|---|
| We analyzed Q3 churn across segments. | Q3 churn rose 4 pts because of onboarding friction in SMB; a 90-day overhaul will fix it. |
| There are pros and cons to entering Brazil. | We should enter Brazil now via partnership rather than direct, because the window is closing and direct entry is too slow. |
| Costs are up across multiple categories. | A $12M cost overrun is concentrated in two vendors; renegotiating both contracts recovers 80% of it. |

### Level 2 — Key Lines

**Definition:** 3–5 statements that support the Governing Thought. Together they must be MECE: Mutually Exclusive (no overlap) and Collectively Exhaustive (no gaps).

Each Key Line is itself a complete-sentence claim, not a topic. "Pricing" is a topic; "Our pricing is 30% above peers in the mid-market segment" is a claim.

**Two valid logical structures for Key Lines:**

1. **Inductive** — each Key Line is a different reason supporting the Governing Thought. Example: *"Enter Brazil now"* supported by (a) market is growing 18% CAGR, (b) two competitors will lock up partners in 6 months, (c) we have an existing platform we can localize.

2. **Deductive** — Key Lines form a sequential argument. Example: *"Discontinue Product X"* supported by (a) Product X loses $3M annually, (b) the loss is structural and cannot be fixed within budget, (c) the resources freed up have a higher-return use.

Inductive is usually clearer for executive decks. Deductive can feel like a logic proof, which slows readers down.

### Level 3 — Supporting Detail

Under each Key Line, the actual evidence: charts, tables, examples, quotes, calculations. This is where most slide content lives.

A good check: every supporting slide should map to exactly one Key Line, and every Key Line should have enough supporting slides to be persuasive (typically 2–4).

## MECE — The Most Important Word

MECE = Mutually Exclusive, Collectively Exhaustive.

- **Mutually Exclusive:** Key Lines don't overlap. If two Key Lines could both be used to argue the same point, one of them is redundant.
- **Collectively Exhaustive:** Together the Key Lines cover all the relevant ground. If a smart skeptic could ask "what about X?" and X isn't in any Key Line, the structure has a gap.

**Quick MECE test:** Read the three Key Lines and ask, *"Is there anything important that isn't covered by any of these? Is there anything that's covered by more than one?"* If yes to either, restructure.

**Common ways to be MECE:**
- By segment (SMB, mid-market, enterprise)
- By time (now, near-term, long-term)
- By function (operations, commercial, organization)
- By stakeholder (customers, employees, shareholders)
- By stage of a process (acquire, retain, expand)

## How to Build a Pyramid (Bottom-Up, Then Read Top-Down)

The pyramid is *read* top-down (Governing Thought first) but *built* bottom-up:

1. List your raw findings — the facts and data you have.
2. Group them into 3–5 buckets. Test for MECE.
3. Write a single-sentence Key Line for each bucket — what does this group of findings *mean*?
4. Read the three Key Lines together. What is the synthesis? Write it as one sentence — that's your Governing Thought.
5. Sanity check: if you removed one Key Line, would the Governing Thought still be true? If yes, that Key Line wasn't load-bearing — drop it or replace it.

## A Common Failure Mode: The "And Now Some Random Slides" Deck

Many decks have a strong opening slide and then drift into ten loosely-related charts. This happens when the author skipped the pyramid step and built slides directly from raw analysis. The fix is always the same: stop, write the Governing Thought, write the Key Lines, then check whether each existing slide maps to a Key Line. The orphan slides usually need to be cut or moved to the appendix.

## Worked Example — MODA Yoga Studio

(From the McKinsey Adaptability, Resilience & Problem Solving program.)

**Question:** Should MODA open an onsite yoga studio?

**Key Lines:**
1. Offering wellness services aligns with MODA's existing health initiative.
2. An onsite yoga studio saves employee time and improves workday efficiency.
3. An onsite studio reinforces socialization and community-building.

**Governing Thought (synthesis):**
> MODA should open an onsite yoga studio because it simultaneously advances our wellness commitment, increases workday efficiency, and builds community — three goals already on our agenda.

This works because:
- It is *one sentence* with *one recommendation*.
- It synthesizes — the three Key Lines together produce a conclusion none of them states alone.
- Removing any one Key Line weakens it, which proves they're load-bearing.

## Quick Reference

```
Analysis complete
        ↓
Synthesis (not summary): what does it all mean?
        ↓
Governing Thought (one sentence with a recommendation)
        ↓
3–5 Key Lines (MECE, complete-sentence claims)
        ↓
Supporting detail per Key Line (charts, data, examples)
```

Once you have this, you have a deck. The slides are just rendering.
