# Slide Archetypes — A Vocabulary of Layouts

Most executive decks are assembled from a small set of slide archetypes. Knowing the vocabulary lets you choose the right layout fast instead of inventing one per slide. The list below covers ~95% of what you'll need.

## The Frame

Every body slide shares a frame:

```
┌────────────────────────────────────────────────────┐
│ ACTION TITLE — full sentence stating the takeaway  │  <- top, bold, 18–24pt
│ Subtitle (optional) — what the chart/data shows    │  <- 12–14pt, gray
├────────────────────────────────────────────────────┤
│                                                    │
│            BODY (content area)                     │  <- ~70% of slide height
│                                                    │
├────────────────────────────────────────────────────┤
│ Footnote¹ — caveats, definitions, methodology      │  <- 8–9pt
│ Source: where the data came from                   │  <- 8–9pt italic
└────────────────────────────────────────────────────┘
```

The action title and source line are non-negotiable. Subtitle and footnote are used when needed.

## The Archetypes

### 1. Cover / Title Slide

First slide. Plain.

```
┌────────────────────────────────────────────────────┐
│                                                    │
│                                                    │
│              [Project Name]                        │
│              [Subtitle]                            │
│                                                    │
│              Prepared for [Audience]               │
│              [Month Year]                          │
│              [Prepared by]                         │
│                                                    │
└────────────────────────────────────────────────────┘
```

No action title here. This is the only slide where a label is acceptable.

### 2. Executive Summary

Slide 2. Often the only slide an executive reads in detail. The title is the Governing Thought; the body is the Key Lines as bullets.

```
┌────────────────────────────────────────────────────┐
│ [Governing Thought as a single sentence]           │
├────────────────────────────────────────────────────┤
│  • [Key Line 1 — full sentence]                    │
│  • [Key Line 2 — full sentence]                    │
│  • [Key Line 3 — full sentence]                    │
│                                                    │
│  [Optional: 1-line "What we're asking" at bottom]  │
└────────────────────────────────────────────────────┘
```

If a busy exec reads only this slide, they should walk away with the recommendation and the three reasons. Test it.

### 3. Section Divider

One per Key Line. Marks a transition.

```
┌────────────────────────────────────────────────────┐
│                                                    │
│   1                                                │
│       [Key Line statement as the divider title]    │
│                                                    │
└────────────────────────────────────────────────────┘
```

Big number, full-sentence Key Line, lots of whitespace. The number is for navigation ("we're now on point 1 of 3").

### 4. Lead-in Slide (Single Exhibit)

The workhorse. Action title + one chart, table, or image that proves it.

```
┌────────────────────────────────────────────────────┐
│ [Action title]                                     │
│ [Subtitle: what's shown]                           │
├────────────────────────────────────────────────────┤
│                                                    │
│           [SINGLE CHART OR TABLE]                  │
│                                                    │
├────────────────────────────────────────────────────┤
│ ¹ Footnote          Source: [source]               │
└────────────────────────────────────────────────────┘
```

Use this for ~60% of body slides. One claim, one piece of evidence.

### 5. Two-Column Comparison

Side-by-side: options, before/after, current/target, build/buy.

```
┌────────────────────────────────────────────────────┐
│ [Action title — usually states the verdict]        │
├──────────────────────────┬─────────────────────────┤
│ Option A                 │ Option B                │
│ ─────────                │ ─────────               │
│ • point                  │ • point                 │
│ • point                  │ • point                 │
│ • point                  │ • point                 │
└──────────────────────────┴─────────────────────────┘
```

Title should state which option wins or the conclusion of the comparison.

### 6. Exhibit with Call-outs

Chart with annotated arrows pointing to specific insights.

```
┌────────────────────────────────────────────────────┐
│ [Action title]                                     │
├────────────────────────────────────────────────────┤
│                       ┌───── Call-out 1 ─┐         │
│                       ▼                            │
│         [CHART WITH MARKED POINTS]                 │
│                          ▲                         │
│            ┌── Call-out 2 ─────┘                   │
└────────────────────────────────────────────────────┘
```

Use when the chart alone isn't self-explanatory. Call-outs are short — 5–10 words each.

### 7. Comparison Table

Multiple options or segments with the same dimensions, ranked or evaluated.

```
┌────────────────────────────────────────────────────┐
│ [Action title]                                     │
├────────┬─────────┬─────────┬─────────┬─────────────┤
│        │ Dim 1   │ Dim 2   │ Dim 3   │ Verdict     │
├────────┼─────────┼─────────┼─────────┼─────────────┤
│ Opt A  │  ●●○    │  ●●●    │  ●○○    │ ★ Recommend │
│ Opt B  │  ●●●    │  ●○○    │  ●●○    │             │
│ Opt C  │  ●○○    │  ●●○    │  ●●●    │             │
└────────┴─────────┴─────────┴─────────┴─────────────┘
```

Harvey balls (●●○) or color cells make scanning faster than numbers.

### 8. Process / Timeline

A multi-step plan or sequence.

```
┌────────────────────────────────────────────────────┐
│ [Action title — usually the recommendation in seq] │
├────────────────────────────────────────────────────┤
│  ┌────┐   ┌────┐   ┌────┐   ┌────┐                 │
│  │ 1  │ → │ 2  │ → │ 3  │ → │ 4  │                 │
│  └────┘   └────┘   └────┘   └────┘                 │
│  Diagnose Design   Pilot    Scale                  │
│  M1       M2-3     M4-6     M7-9                   │
└────────────────────────────────────────────────────┘
```

Use for roadmaps, implementation plans, phased recommendations.

### 9. Recommendation Slide

Penultimate slide. The action.

```
┌────────────────────────────────────────────────────┐
│ Recommendation: [Restated Governing Thought]       │
├────────────────────────────────────────────────────┤
│  Action 1     Owner     Date                       │
│  Action 2     Owner     Date                       │
│  Action 3     Owner     Date                       │
│                                                    │
│  Investment:  $X      Expected return:  $Y in N mo │
└────────────────────────────────────────────────────┘
```

Concrete. Owners. Dates. Numbers. No fluff.

### 10. Appendix Slides

Backup data, methodology, deep dives. These should be self-contained and labeled. Most appendix slides should have the action title, even though they're appendix — they may be referenced standalone.

## Choosing the Right Archetype

| If you want to… | Use… |
|---|---|
| Open the deck | Cover |
| Land the recommendation in 30 seconds | Executive Summary |
| Mark a section transition | Section Divider |
| Prove one claim with one piece of evidence | Lead-in |
| Compare two options | Two-Column |
| Show data with insight | Exhibit with Call-outs |
| Compare 3+ options on shared dimensions | Comparison Table |
| Show a multi-step plan | Process / Timeline |
| Close with the ask | Recommendation |

Most decks use Lead-in slides for the bulk of the body, with the other archetypes as accents. If your deck has 12 different layouts, that's a sign of inconsistency — restrict yourself to 4–6 archetypes per deck.

## A Quick Audit Question

After drafting the ghost deck, ask: *can each slide be classified as one of these archetypes?* If a slide doesn't fit any, it's likely doing two things at once — split it.
