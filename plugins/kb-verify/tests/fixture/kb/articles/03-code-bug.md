# Solicitar reembolso de uma cobrança

## Prazo

O reembolso pode ser solicitado em até **10 dias** após a data da cobrança. Depois desse prazo, o pedido é recusado com a mensagem **"O prazo para solicitar o reembolso desta cobrança já terminou."**

## Quem pode solicitar

Somente **Donos** e **Administradores** do workspace.

## Passo a passo

1. Acesse **Configurações → Faturamento** e abra a aba **Reembolsos**.
2. Localize a cobrança na lista e clique em **Solicitar reembolso**.
3. Se quiser, descreva o motivo no campo **Motivo (opcional)**.
4. A mensagem **"Pedido de reembolso recebido. O valor volta ao método de pagamento original em até 5 dias úteis."** confirma o envio.

## Observações

- Cada cobrança aceita apenas um pedido de reembolso. Um segundo pedido mostra **"Já existe um pedido de reembolso para esta cobrança."**
