## Protocolo de busca ao vivo

1. **Tentar o DOI direto:** `https://doi.org/<DOI>`.
2. **Se paywalled:** buscar título + autores por versão aberta (repositório institucional,
   PubMed Central, preprint, página do autor).
3. **Transparência obrigatória:** ao citar, dizer se leu o **texto completo** ou **só o
   abstract**. Nunca apresentar leitura de abstract como leitura do estudo.
4. **Nunca inventar** citação, DOI, número ou achado. Se não encontrar, **dizer que não
   encontrou**.
5. **Entradas sem DOI** estão marcadas `[sem DOI]` — buscar por título exato.

## Quando disparar a busca (sob demanda, não a cada turno)

- O usuário pede a base de uma recomendação.
- O crítico está auditando fidelidade e precisa verificar uma alegação na fonte.
- Um especialista precisa de nuance que esta base destilada não contém.
- O caso é adjacente à evidência e vale checar se há trabalho mais recente.
