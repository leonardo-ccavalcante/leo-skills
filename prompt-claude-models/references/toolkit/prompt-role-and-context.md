**Reforços (15)**

(claude-prompting-best-practices, "Give Claude a role")
- `SKILL.md:81` · injeção via texto colado (Opus 5.5) — Além da persona no system, no Opus 5.5 envolver texto colado pelo usuário em <pasted_content id="…">…</pasted_content id="…"> com ID aleatório e a nota oficial no system, para que instruções dentro dele não sobrescrevam a persona. (prompting-claude-opus-5-5, "Mark pasted text in user messages")
- `SKILL.md:58` · implicação comportamental + porquê — Além do comportamento, dar o motivo ('...porque o leitor é iniciante'); o Claude generaliza a partir da explicação, e o Fable 5 rende mais quando entende a intenção. (claude-prompting-best-practices, "Add context to improve performance")
- `SKILL.md:57` · persona concreta vs. genérica — O exemplo oficial é uma única frase com especialização ('You are a helpful coding assistant specializing in Python.'): o que conta é o recorte de domínio, não superlativos. (claude-prompting-best-practices, "Give Claude a role")
- `SKILL.md:89` · lembrete de persona sem prefill — O 'reminder' nunca é um turno de assistant pré-preenchido (400 em Claude 4.6+); vai no turno do usuário ou, no Fable 5.1/Opus 5.5, como mid-conversation system message. (claude-prompting-best-practices, "Migrating away from prefilled responses")
- `SKILL.md:49` · tarefas mecânicas: effort baixo, saída estruturada — Para classificação/extração/conversão com alvo Claude: effort `low` (a doc o reserva para tarefas curtas e delimitadas e cargas sensíveis à latência) e, para rótulos, ferramenta com enum ou structured outputs em vez de pedir 'só JSON'. As páginas não dizem nada sobre dispensar a persona nessas tarefas. (prompting-claude-sonnet-5, "Calibrating effort and thinking depth"); (claude-prompting-best-practices, "Migrating away from prefilled responses")
- `SKILL.md:50` · persona x 'só JSON' — Para JSON estrito no Claude, preferir Structured Outputs (ou tool com schema) a instruções de 'no commentary'; prefill de '{' não é opção (400). (claude-prompting-best-practices, "Migrating away from prefilled responses")
