## Business Model Canvas (9 blocks)

| Block | Content |
|---|---|
| Customer segments | <who you serve; the segments that pay> |
| Value propositions | <the job done or pain removed, per segment> |
| Channels | <how the value reaches each segment> |
| Customer relationships | <how you get, keep, and grow each segment> |
| Revenue streams | <what each segment pays for and how: subscription, transaction, license, service> |
| Key resources | <assets the model cannot run without> |
| Key activities | <what the company must do well every week> |
| Key partnerships | <who does what you deliberately do not> |
| Cost structure | <the biggest cost drivers; fixed vs variable> |

## Lean Canvas

| Block | Content |
|---|---|
| Problem | <top three problems; existing alternatives> |
| Customer segments | <target customers and early adopters> |
| Unique value proposition | <single clear message: why you are different and worth attention> |
| Solution | <top three features that answer the problems> |
| Channels | <path to customers> |
| Revenue streams | <revenue model, gross margin logic> |
| Cost structure | <customer acquisition costs, distribution, hosting, people> |
| Key metrics | <the numbers that tell you the model works; each one tagged in the inputs table> |
| Unfair advantage | <what cannot be easily copied or bought; "none yet" is an honest answer> |

## Startup Canvas (pre-revenue extension)

<!-- Lean Canvas core plus the three blocks an idea-stage conversation needs.
     Use when stage is idea or validating and mode is pre-revenue. -->

| Block | Content |
|---|---|
| Vision | <what the world looks like if this works, one sentence> |
| Problem | <as in Lean Canvas> |
| Customer segments | <as in Lean Canvas; name the first ten customers if you can> |
| Unique value proposition | <as in Lean Canvas> |
| Solution | <as in Lean Canvas> |
| Channels | <as in Lean Canvas> |
| Revenue streams | <intended model; label every figure as assumption until real> |
| Cost structure | <the burn drivers for the next two quarters> |
| Key metrics | <evidence targets, not vanity: interviews done, LOIs signed, waitlist conversions> |
| Unfair advantage | <as in Lean Canvas> |
| Traction | <what is real today: interviews, pilots, signed letters, code shipped; "none" is honest> |
| Ask | <what you need next: amount, runway it buys, the milestone it funds; figures come from fa.sh artifacts> |
